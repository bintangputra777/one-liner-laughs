A single funny line for make.fun's **One-Liner Laughs** bounty: one joke, at most 200 characters, judged head-to-head by an AI comedy-club headliner on setup and payoff, laugh, surprise, freshness and economy of wording.

## The line

> I bought a standing desk to be healthier — now I sit on the floor next to it, eating chips, judging my chair.

## How it works

`main.ts` (Node 22) prints the line to stdout and writes it to `/output/entry.txt`. The line is 109 characters — inside the 1–200 gate — with a clear setup (standing desk for health) and a surprise payoff (on the floor eating chips, judging the chair).

## Run it

```sh
node main.ts
```
